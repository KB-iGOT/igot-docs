# Curated Program

An editorially assembled collection of courses enrolled as one unit —
auto-assigned batch, progress rolled up from the child courses.

- **Category**: `primaryCategory = "Curated Program"`
- **Enrol**: `curatedprogram/v1/enrol` (Moderated Program: `openprogram/v1/enrol`)

A parent collection whose children are ordinary courses. Enrolling in the
program **auto-assigns** the learner into its batch in one call — no approval,
no batch picking — and the program's completion is **computed from the child
courses'** individual enrolments.
