# Course

The standard self-paced unit of learning — one-click enrolment, node-by-node
progress, Karma Points and a certificate on completion.

- **Category**: `primaryCategory = "Course"`
- **Consumption route**: `/app/toc/:courseId`

Unlike a Blended Program, a Course has **no approval workflow**: tapping Enrol
writes the enrolment directly and the course lands in My Learning at 0%.
Progress is tracked per content node, Karma Points accrue on completion
events, and a certificate issues when every mandatory node is complete.

Every other Learning Hub category is best understood as **this pipeline plus
one twist**: Blended adds an approval workflow, Curated adds auto-assignment,
Assigned Courses adds a rules engine, assessments swap the player for the
assessment engine.
