What it is

The learner-facing view of content assignment: courses an MDO has directed at a user, surfaced as “My Assigned Courses” with mandatory-course nudges. This is the one Learning Hub feature whose backend is fully in the attached repos — CourseAccessController and CourseAccessServiceImpl in cb-ext-course-service.

Rules, not lists

Assignments resolve from cached access-setting rules, then a composite search finds matching courses.

External courses too

A dedicated endpoint resolves assigned partner content via the CIOS integration search.

Admin view

An admin can read any user's assignments through the admin variant.
