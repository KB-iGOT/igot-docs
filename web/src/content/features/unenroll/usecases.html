User flow

1. Unenrollment flow. Preconditions: the user is logged in, enrolled in the course, has not completed it, and the content type is Course.

  1. Login.
  2. Open the course card.
  3. Navigate to the TOC.
  4. Open the ⋯ menu in the TOC header.
  5. Select Unenroll, which opens the confirmation modal.
  6. Confirm? The modal explains that the course is removed from the active list, that hours, karma and badges are reversed, and that progress is saved for later. Cancel aborts with no change.
  7. Confirm Unenrollment.
  8. The course moves to the Unenrolled section.
  9. Complete: metrics are recalculated and a snapshot is stored.

2. Re-enrollment flow. The active surface is My Learning → Unenrolled Courses.

  1. User login.
  2. Open My Learning.
  3. Open Unenrolled Courses.
  4. Open the course.
  5. Navigate to the TOC.
  6. Click Re-enroll (on the TOC page only).
  7. End: enrollment and progress are restored.
